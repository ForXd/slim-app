# 字体调整

用户要求保留暖纸、朱红主题，改善字体协调性。

- 品牌、日期、页面标题、章节标题及挑战名称保留 Noto Serif CJK Regular；移除对 Regular 字体施加的合成粗体。
- 正文、按钮、表单、底部导航使用 Android 系统无衬线字体；说明用正常字重，操作和强调信息用 Medium。所有操作按钮统一无衬线，不再被首页按钮覆盖成宋体。
- 体重、餐数、挑战进度和能量读数使用无衬线 Medium 数字，启用等宽数字特性；单位用较小的正常字重，避免与读数争抢。
- 字号：品牌32、日期30、页面标题26、章节22、挑战名21、主操作20、正文14–16、辅助信息12–13。卡片眉题和序号保留10–11。
- 去除按钮额外字间距；副标题使用统一字距代替手动空格。正文约1.2倍行高，标题与数字保持紧凑。首页说明使用均衡换行策略。
- 图像、纸纹、配色与功能保持不变；未新增字体文件或联网字体依赖。
