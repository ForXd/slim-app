# Slim App

Maintained product is native Android Java, package cn.qingji.diary, minimum API 28.

- Sources: android/src/cn/qingji/diary; build: sh android/build.sh (JDK 17, Android SDK 35).
- Preserve JournalStore/ChallengeStore schemas and existing signing identity for upgrades.
- Keep all keys, keystores, credentials and generated APKs out of git. Release binaries are GitHub Release assets.
- Do not auto-record inferred food; require user confirmation of candidate and portion.
- Update files must pass size, SHA256, package, version and installed signing certificate checks before installation.
- Challenge count is completed cells (maximum 100), not distinct calendar dates.
- Run FeatureCheck for challenge/update changes and NativeCheck for food database/model changes on Android.
- Keep source attribution and licenses when updating models, nutrition data or test photos.
- Native version comes from android/AndroidManifest.xml. Release metadata is generated by scripts/release.sh.
