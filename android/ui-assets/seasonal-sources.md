# Seasonal watercolor assets

Generated for 靓女修炼笔记 on 2026-11-06 with the built-in OpenAI `image_gen` tool, using the local imagegen skill. Four independent generation calls were run; no CLI/API fallback was used. These are original generated decorative assets for this project, not stock photographs.

The existing project watercolor `tomato-branch.png` was viewed only for visual style reference. It was not modified and was not passed as an image input. The autumn subject is explicitly an orange persimmon branch, not tomato. The watercolor illustrations have real PNG alpha; their unpainted areas are transparent. The original generated files were copied into this directory without raster editing or alpha removal.

Intended use: the home page's upper-right 146 × 116 dp illustration. The warm paper texture, vermilion actions and semantic energy colors remain unchanged. The app's automatic selection uses calendar months (March–May spring, June–August summer, September–November autumn, December–February winter); it does not claim astronomical or 24-solar-term precision.
