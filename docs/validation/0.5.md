## 真实更新链路

1. 安装带更新模块的测试基线0.4.9（versionCode4；并非历史公开版本）。
2. 保存1200 kcal计划、68.5kg体重及两格挑战。
3. 从真实 `ForXd/slim-app` Release地址检查到0.5.0，下载27.99MB APK。
4. 大小、SHA256、包名、版本及签名校验成功；进入系统来源授权页，再由系统安装器确认更新。
5. 安装后系统报告versionCode5/versionName0.5.0，计划、体重及挑战保留。
6. 本地覆盖安装0.5.1（versionCode6），功能测试再次通过。0.5.1仅优化转场可见区域硬件层缓存，更新协议不变。

0.4及以前没有更新模块，必须先手动安装本次APK。发布包延续原本签名，证书SHA256：
`dde7659242a72af8dbfa0798827a15bfec3be64e84a2adde2e928a61bb111751`。

## 动画与性能限制

模拟器开启动画后，重复切换今日/趋势/百次/计划16次：0.5.0的P50/P95/P99帧耗时为40/61/105ms；使用可见区域缓存的0.5.1为38/61/69ms。模拟图形环境仍报告大量慢帧，因此这些结果不能支持“稳定60fps”的声明；需要在真实中低端设备上继续测量。硬件层仅在180ms转场期间使用，结束后释放。
