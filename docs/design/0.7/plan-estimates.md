# 计划估算的口径与局限

身体信息只用于本地估算，确认保存之前不会修改现有计划。资料与计划使用一次 SharedPreferences commit 保存；估算用的体重不会自动写为体重记录。

## 公式和来源

- 静息消耗采用 Mifflin–St Jeor 简化式：`10×kg + 6.25×cm − 5×年龄 + 性别常数`，男性+5、女性−161。依据：[原始研究](https://pubmed.ncbi.nlm.nih.gov/2305711/)。原研究19–78岁，本产品成年输入限制18–78岁；18岁是成人范围边界，并不是单独验证过的精确估计。
- 维持热量为静息估算乘日常活动系数1.2 / 1.375 / 1.55；档位参考 [Texas HHS](https://www.hhs.texas.gov/sites/default/files/documents/common-comparative-standards-for-rds-ltc-settings.pdf)。本产品把它作为日常活动起点，UI明确排除另记专项运动，以免再次把同一运动加入消耗。
- 温和、标准方案分别尝试减少250、500千卡/日。自动方案的产品保守边界为女性1200、男性1500；参考 [AHA/ACC/TOS成人体重管理指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC5819889/)，不是对所有人的最低安全摄入保证。目标不能因该边界反而高于维持值，低BMI不自动给出减量方案。
- 自定义继续允许1–6500千卡；它用于记录用户已有目标，不代表系统认可每个数值适合每个人。

## 展示方式

两步操作：身体信息→计划对比。取消、修改或只看结果都不改变已保存计划。方案卡使用实际目标与维持值之差，不能在下限截断后仍声称固定500千卡差值。

每周和4周参考采用 `实际日差值 × 天数 / 7700` 的短期能量换算，并标注「初期理论参考，不代表实际体重变化」。这不是动态人体模型，不给长期达标日期。代谢适应、水分、实际摄入及运动等会使体重变化偏离线性换算；依据 [NIDDK 对静态热量规则的说明](https://www.niddk.nih.gov/health-information/professionals/diabetes-discoveries-practice/nih-body-weight-planner)。

原有大段说明移入按需打开的「估算说明」，保留必要的来源和适用范围。没有要求用户上传身体资料。
