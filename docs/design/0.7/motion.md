# 堆叠卡片动效参考与实现

用户要求：检查更新入口必须明确；多个百次挑战改成有层次的堆叠滑动，保留暖纸与朱红视觉。

参考一手项目：
- [CardStackView](https://github.com/yuyakaido/CardStackView)：多层缩放、跟手旋转、阈值切换、取消回弹。项目默认3层、0.95缩放、30%阈值；可调整层距与旋转。
- [SwipingCards](https://github.com/makzimi/SwipingCards)：顶部卡片跟手，后方卡片推进，弹性回位。其循环换位语义不直接用于本应用。
- [Android touch interception](https://developer.android.com/develop/ui/views/touch-and-input/gestures/viewgroup)：使用 touch slop 区分水平与垂直意图。DOWN 暂时保留子级手势判定；确认垂直意图后释放父级，避免斜向横滑先被 ScrollView 抢走。

实现选择：原生Java FrameLayout，最多三个卡片View，使用translation/scale/rotation属性动画。未复制上述库源码或引入其依赖。

- 静止态：三张不透明纸卡，缩放1/.955/.91，向下错位0/21/42dp，轻阴影。
- 拖动：顶卡随指移动，倾斜不超过7°；下一层随进度抬升和放大。
- 提交：横向距离超过24%卡宽，或明确快速甩动；左滑下一个，右滑上一个。240ms完成，完成时才变更当前挑战及下方百格。
- 回弹：不足阈值、首尾越界、多指或取消均不改变当前挑战；280ms轻微回弹。
- 边界：不循环、不删除、不打卡；一个挑战时禁用横向切换。保留上一个/下一个按钮及无障碍滚动动作。
- 动画进行中的新手势整段忽略，防止旧坐标误切；搜索/归档销毁旧卡组时取消动画与旧回调。
- 系统动画关闭时直接落位。没有网络、图片解码或列表重建在逐帧拖动回调中执行。

更新入口：首页首屏、所有其他标签页标题栏均显示「检查更新」。点击直接打开现有安全更新面板并立即手动检查；旧计划页入口保留。
