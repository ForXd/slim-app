# 0.7.0 设计 QA

- 保留暖纸、朱红与水彩风格，应用名统一为「靓女修炼笔记」，新图标为笔记与新芽。
- 字体分为正常宋体标题、系统黑体正文/操作、等宽数字；移除模拟粗体，正文更紧凑。输入/选择/保存采用两步计划卡片，短位移转场遵循系统动画开关。
- 首页能量卡提升到摘要之后；摄入值、目标、剩余/超出状态与运动入口有明确层级。绿/红是语义状态色，季节插画不会改动它们。
- 日历以日期格与记录圆点替代全部记录列表；点选返回当天内容，历史视图可回到今天。未来日期禁用。
- 月度/年度趋势使用紧凑分段选择、摘要卡、原生图表与点选详情；不把漏记补成零，不把年视图压成365根柱。
- 百次挑战三层纸卡，拖动仅改变变换属性，落位后更新百格。边界抵抗与轻微回弹，动画中触摸不造成额外切换。
- 检查更新位于首屏与所有页标题栏；重复品牌副标题、冗余页内提示已简化。
- 首页语录有铅笔入口；保存、取消、恢复默认均提供明确操作。主题支持按月份自动与四季手动选择，水彩资产均透明且打包离线可用。

全部截图来自隔离模拟器。功能证据见 `../../validation/0.7/README.md`；字体与公式说明分别见 `typography.md`、`plan-estimates.md`，动效参考见 `motion.md`。
