# 0.7.0 验证

环境：API 37 ARM64 Android 模拟器，1080×2400px、420dpi，宿主GPU（Apple M1 Pro / Metal）加速。测试数据由隔离模拟器的 UiFixture 创建，正式APK没有预填记录或测试运行器。

## 功能回归

- `FeatureCheck.txt`：挑战100格、撤销、归档、持久化、搜索、照片路径约束及更新校验通过。
- `DeckCheck.txt`：真实附着视图的短拖回弹、阈值切换、首尾底卡保留、取消/多指、动画中二次触摸、移除视图取消，以及ScrollView斜向横滑/纵向滚动仲裁通过。
- `TrendCheck.txt`：闰年2月、逐日求和、未知/零/漏记区分、年度按有记录日聚合、同日最新体重与月均、未来记录排除通过。
- `RevisionCheck.txt`：Mifflin数值、实际差值、自动方案下限、低BMI、自定义小于1500、无效输入、月历及四季边界通过。
- `EnergyCheck.txt`：原生进度颜色/文案在低于、等于、超出、空记录、未知热量、无目标时正确；专项运动增加消耗，不改摄入额度。使用独立测试Prefs，原数据无变化。
- `UiFixture.txt`：0.6.0→0.7.0同签名覆盖安装后，体重、餐食、照片引用、1200千卡目标和5个挑战保留。
- `ui-checks.json`：实际ADB点击/输入/滑动完整通过：改名、更新入口、堆叠卡搜索归档、日历选日返回今日、语录保存恢复、月度年度切换、身体信息计算保存、直接设置1200、冬季主题手选及自动恢复。

未改动食品数据库或识别模型，本轮未重复NativeCheck；其已知识别局限仍见0.6验证报告。

## 视觉与性能

实际截图在 `../../design/0.7/`，包括首页、三层卡片/拖动、日历、月度年度趋势、计划输入/结果、冬季主题、360dp/1.3倍字体。已逐页打开检查。

性能原始记录：`deck-frames-hardware.txt`。预热后12次左右切换，576帧中26帧错过帧截止时间（4.51%），P50/P95/P99为17/19/20ms；这是宿主GPU模拟器数据，不代表所有真机的稳定帧率。运行时错误检查保存在 `runtime-errors.txt`。

四季插画为内建image_gen原始输出；路径、透明通道说明和完整提示词：`../../../android/ui-assets/seasonal-sources.md`。主题按月份切换，不声称精确节气切换。

## 发布约束

沿用原包名与签名，自动更新仍验证实际APK大小、SHA256、包名、版本和签名。个人资料与语录保存在本地；计算预览不自动保存计划或体重。保存计划一次提交资料和目标。

真实手机性能、OEM安装器尚未验证。计划热量与体重变化为估算，计算口径和原始来源见 `../../design/0.7/plan-estimates.md`。
